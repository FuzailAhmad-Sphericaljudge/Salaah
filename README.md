# Salaah Home Page

Home page for Salaah, The Mentor Community of ABES Engineering College. Built with React and Vite.

## Run locally

```
npm install
npm run dev
```

## Build

```
npm run build
```

The production files are created in the `dist` folder.

## Deploy

Import this repository on Vercel or Netlify. Use the build command `npm run build` and the output directory `dist`.
